# Kalkulator-Dosis-Obat-Anak
Seorang Dokter ingin membuat sistem sederhana untuk Menghitung dosis obat yang aman unuk anak tergantung dengan berat badan anak dan dosis standar obat untuk anak, dan jika total dosis melebihi dosis maksimum harian (misalnya 500mg), maka peringatan akan muncul "Dosis melebihi batas aman, konsultasikan dengan dokter."
